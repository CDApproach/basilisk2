# Basilisk im Ödland

Ein Snake-II-Klon im 16-Bit-Stil: Ein Basilisk frisst Mutanten in einer dystopischen Ruinenlandschaft.

**Spielen:** https://cdapproach.github.io/basilisk2/

- Steuerung: Pfeiltasten oder WASD, `P` Pause, `M` Ton an/aus (auf dem Handy: wischen oder Steuerkreuz)
- Glibber und Augling sind normales Futter, die Zweikopfratte ist der Bonus nach jedem 5. Happen
- Keine Wände: Wer über den Rand gleitet, kommt auf der anderen Seite wieder heraus
- Die Bestenliste wird nur im eigenen Browser gespeichert

Alles steckt in einer einzigen Datei, `index.html`, ohne Build-Schritt und ohne Abhängigkeiten außer den Google Fonts.
